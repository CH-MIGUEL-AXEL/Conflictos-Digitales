# Cómo se hizo COLIBRÍ EN UNIDAD

## Explicación breve para presentar

Partimos de la propuesta de COLIBRÍ EN UNIDAD y organizamos su contenido en cuatro entradas: aprender a convivir, solicitar apoyo, aclarar y proponer, y dar seguimiento a los acuerdos. Con apoyo técnico, desarrollamos la página en Angular y Tailwind CSS, integrando el logotipo, las fotografías y un diseño adaptable a celulares y computadoras. Guardamos el código y su historial de cambios en GitHub y lo conectamos con Cloudflare Workers, donde se compila y publica automáticamente al subir actualizaciones. Esta primera versión presenta la información del proyecto; la recepción de solicitudes y el seguimiento privado requieren una etapa posterior.

## Si preguntan por las herramientas

- Angular organiza el contenido y las interacciones de la página.
- Tailwind CSS y los estilos propios dan forma al diseño visual y su adaptación a distintas pantallas.
- Git guarda el historial de cambios; GitHub aloja el repositorio del proyecto.
- Cloudflare Workers publica la página en internet y está conectado al repositorio para actualizarla.

El servicio utilizado es Cloudflare Workers. Amazon CloudFront es un servicio diferente y no forma parte de este despliegue.
